MHD flow of a Williamson fluid over a stretching sheet

Effects of temperature-dependent thermal conductivity and absorptive/generative heat transfer on the MHD flow of a Williamson fluid over a nonlinear stretching sheet

Honours mini-dissertation · 2026 MATLAB Spectral Relaxation Method bvp4c 2nd place · UL–UJ–UNIVEN Symposium

Supervised by Prof S. Shateyi, co-supervised by Dr K. Muzhinji, University of Venda.

The problem

When a polymer sheet is extruded or a metal strip is cooled, it is stretched through a surrounding liquid. This project models a shear-thinning (Williamson) liquid flowing over such a sheet under a magnetic field, where the liquid's thermal conductivity changes with temperature and heat can be absorbed or generated inside it. The aim is to understand how each physical effect changes the drag on the sheet and how fast it cools.

The model

Starting from the continuity, momentum and energy equations, I used similarity variables to reduce the partial differential equations to a coupled system of nonlinear ordinary differential equations:

f‴ + We f″f‴ + n+12 f f″ − n(f′)2 − M f′ = 0
(1 + εθ)θ″ + ε(θ′)2 + Pr n+12 f θ′ − Pr n f′θ + Pr H θ = 0
with f(0) = 0, f′(0) = 1, θ(0) = 1 and f′(∞) = 0, θ(∞) = 0

Parameters: Weissenberg number We, magnetic parameter M, stretching index n, Prandtl number Pr, conductivity parameter ε and heat source/sink parameter H.

The method

  1. Solved the system with the Spectral Relaxation Method (SRM), which decouples the equations and solves each one in turn by Chebyshev spectral collocation.
  2. Used N = 100 collocation points on a domain truncated at L = 30, with under-relaxation factor ω = 0.9 and a convergence tolerance of 10−10.
  3. Checked every result against MATLAB's built-in bvp4c solver, and validated the code against an exact solution and published results (Bilal et al., 2017).

Key findings

  • A stronger magnetic field increases the drag on the sheet but reduces the rate of heat transfer, a trade-off to manage in magnetically controlled steel casting.
  • A higher Weissenberg number lowers the skin friction, because the fluid is shear-thinning.
  • Heat transfer rises strongly with the Prandtl number and with heat absorption, but falls when conductivity is more temperature-sensitive. A constant-conductivity model would therefore overstate how fast a polymer sheet cools.
  • With heat generation, no reliable solution exists for Pr ≤ 1.

Code: one SRM iteration

The SRM solves the momentum equation for f with the nonlinear terms taken from the previous iteration, then uses the updated f to solve the energy equation for θ. Both updates are under-relaxed for stability. This excerpt is simplified from my MATLAB solver; D1, D2, D3 are Chebyshev derivative matrices mapped to [0, L].

% --- Momentum equation: linear in f_{r+1} ---
A1 = diag(1 + We*(D2*fr))*D3 + ((n+1)/2)*diag(fr)*D2 - M*D1;
B1 = n*(D1*fr).^2;
A1(N+1,:) = 0;  A1(N+1,N+1) = 1;  B1(N+1) = 0;   % f(0) = 0
A1(N,:)   = D1(N+1,:);            B1(N)   = 1;   % f'(0) = 1
A1(1,:)   = D1(1,:);              B1(1)   = 0;   % f'(inf) = 0
frt   = A1\B1;
fnorm = norm(frt - fr, inf);
fr    = omega*frt + (1 - omega)*fr;               % under-relaxation, omega = 0.9

% --- Energy equation: uses the updated f ---
A2 = diag(1 + epsilon*thetar)*D2 + Pr*((n+1)/2)*diag(fr)*D1 ...
     - n*Pr*diag(D1*fr) + Pr*H*I;
B2 = -epsilon*(D1*thetar).^2;
A2(N+1,:) = 0;  A2(N+1,N+1) = 1;  B2(N+1) = 1;   % theta(0) = 1
A2(1,:)   = 0;  A2(1,1)     = 1;  B2(1)   = 0;   % theta(inf) = 0
thetart   = A2\B2;
thetanorm = norm(thetart - thetar, inf);
thetar    = omega*thetart + (1 - omega)*thetar;

% --- Stop when the decoupling error is below tolerance ---
Ed = max([fnorm thetanorm]);                      % loop while Ed > 1e-10

Code: Chebyshev differentiation matrix

The derivative matrices come from this function, which builds the Chebyshev differentiation matrix on the Gauss–Lobatto points (after Trefethen, Spectral Methods in MATLAB, 2000):

function [D, x] = cheb(N)
% Chebyshev differentiation matrix D and Gauss–Lobatto points x on [-1, 1]
if N == 0
    D = 0;
    x = 1;
    return
end
x = cos(pi * (0:N) / N)';                   % collocation points
c = [2; ones(N - 1, 1); 2] .* (-1).^(0:N)';
X = repmat(x, 1, N + 1);
dX = X - X';
D = (c * (1 ./ c)') ./ (dX + (eye(N + 1)));  % off-diagonal entries
D = D - diag(sum(D, 2));                    % diagonal: rows sum to zero
end

Results were cross-checked with a separate MATLAB bvp4c program that solves the same system as five first-order ODEs.
